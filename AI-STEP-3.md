# Chess Evolution AI — Step 3: Evolution-aware tactical search

This milestone strengthens the existing computer opponent without changing the game's rules or replacing its engine.

## Search improvements

- Quiescence search extends leaf positions through forcing captures, promotions, and all legal evasions while in check. This helps avoid evaluating positions in the middle of a capture sequence.
- A bounded transposition table reuses previously searched positions. It stores exact, lower-bound and upper-bound entries and normalizes mate scores by ply.
- Move ordering now combines the transposition-table move, capture value, newly inherited powers, promotions, castling, killer moves and a history heuristic.
- Iterative deepening and alpha-beta pruning remain in place.

## Chess Evolution evaluation improvements

- Values each distinct inherited capability once.
- Adds modest bonuses for useful capability combinations, including Knight + slider, Rook + Bishop, and the full Queen/Rook/Bishop/Knight set.
- Penalizes attacked, undefended pieces more than defended pieces; evolved units are valued using their native material plus acquired powers.
- Adds small bonuses for king shelter and advanced pawns.
- Recognizes multi-target pressure from pieces with native or inherited movement capabilities. This is a positional heuristic, not a proof that the targets can be won.
- Uses bulk attack maps generated by the rules engine. Tests verify that these maps match square-by-square attack detection for evolved pieces.

## Regression tests added

- Finds a forced checkmate in one.
- Avoids a poisoned rook capture when the opponent can immediately recapture.
- Prefers a safe evolved unit over an exposed one in evaluation.
- Reuses transpositions reached by different move orders.
- Reconstructs the 30-ply position from the user's supplied match and independently finds the White pawn's final move `e5-f7`, scoring it as mate; applying it produces checkmate.

## Install / run

Requires the existing Node.js version in `package.json` (22 or newer, below 27). No extra dependencies are required.

```powershell
npm install
npm test
npm start
```

Open `http://localhost:3000` and choose **Play Against Computer**. The AI still runs in the existing Web Worker.

## Important limitations

- This is an improved handcrafted search engine, not a trained neural network.
- Difficulty presets are resource limits, not calibrated Elo ratings.
- The tactical evaluation is heuristic. Multi-target pressure can indicate a fork-like opportunity, but it does not prove the opponent cannot defend.
- Search time varies by device. The worker keeps the board UI responsive, but Expert can take several seconds, especially on phones.
